# Input Handle React App
Logic only, not UI focused.

Input Handle React App built with React, Vite, and Tailwind CSS.

## Features

- Minimal input hanle with distucture, onClick, onChange, event-handler and useState in a single input handler function.

## Tech Stack

- React
- Vite
- Tailwind CSS

## Getting Started

### Prerequisites

- Node.js (LTS recommended)
- npm

### Install and run

```bash
git clone <your-repository-url>
cd input-handle
npm install
npm run dev
```

Open the local URL printed by Vite in your browser.

## Available Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the development server |
| `npm run build` | Create a production build in `dist/` |
| `npm run preview` | Preview the production build locally |
| `npm run lint` | Run ESLint |
